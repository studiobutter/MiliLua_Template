# Miliastra Wonderland Lua Development Setup Script

This script is for mainly setting up your development enviroment by installing VS Code and the required extensions if you haven't already, setup your lua workspace in VS Code so you can get up and start making Wonderland Stages in no-time.

You can Download the Script `setup.ps1` and run directly, or run this command to get started:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex "&{$((New-Object System.Net.WebClient).DownloadString('https://raw.githubusercontent.com/studiobutter/MiliLua_Template/refs/heads/main/setup.ps1'))}"
```
